## Git Workflow

The basic workflow followed in this project is:

1. Create or clone a repository
2. Create or modify files
3. Check changes using `git status`
4. Stage changes using `git add`
5. Commit changes using `git commit`
6. Push changes using `git push`
7. Create branches for features
8. Merge completed features into the main branch
